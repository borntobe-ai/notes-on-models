# 构建你自己的应用

[English](./index.md) | 简体中文

让我们构建一个简单的搜索智能体，查找最新信息来回答你的问题。

[查看示例项目](https://github.com/borntobe-ai/simple-agent)

## 基本循环

核心交互很直观：你向模型发送提示词，模型可以根据已有知识和对话上下文作答。如果你还为它提供了可用的工具，它就可以请求调用工具，获取信息或执行操作。

你的应用执行模型请求的工具调用，并将结果返回给模型。随后，模型可以继续请求调用工具，也可以给出最终答案。这个循环就是一个简单智能体的基础。

## 四种消息角色

为了支持这个循环，我们将对话中的消息分为四种角色：

- **System（系统）**：定义智能体行为的指令。
- **User（用户）**：用户提出的问题或请求。
- **Assistant（助手）**：模型的回复，包括工具调用请求。
- **Tool（工具）**：应用执行工具后返回的结果。

这些消息共同构成对话历史，为模型的每一步提供上下文。

## 把各个部分连接起来

**编排器（orchestrator）**负责协调模型、工具和对话历史。每当收到一条新的用户消息时，它会：

1. 将消息加入对话历史。
2. 将对话历史和可用工具的定义发送给 AI 服务提供方。
3. 将模型的回复追加到对话历史中。
4. 如果模型请求调用工具，就执行调用，将结果加入对话历史，再次请求模型响应。
5. 当模型返回最终文本回复时，结束这一轮；如果发生错误或达到步数上限，也会停止循环。

在示例项目中，我们使用 DeepSeek Flash 作为模型，并通过 DeepSeek 的网页搜索工具获取最新信息。编排器将两者连接起来，组成一个简单的搜索智能体。

最简单的智能体，就是根据你的提示词，借助模型和工具完成任务的软件。模型决定请求调用哪些工具，应用则负责执行调用，并将结果反馈给模型。

获取一个 [DeepSeek API 密钥](https://platform.deepseek.com/)，按照示例项目中的说明完成配置，再试着提出一个需要最新信息才能回答的问题。你就能看到模型与工具之间的循环是如何运作的。
